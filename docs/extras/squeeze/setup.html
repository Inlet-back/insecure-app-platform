Extra 0 — 準備

Coreの2つのAPKを消さず、Squeeze用の2つを追加する

Extra所要 10分AVD専用
Coreには触れません
Squeezeは別パッケージです。元の被害者APKとAttacker APK、その保存データを残したまま追加できます。

手順1Extraの2つを入れる

Coreの3つとは別枠で、Extra用のAPKを2つ配っています。Coreの2つを消す必要はありません。

adb install -r squeeze-debug.apk
adb install -r squeeze-attacker-debug.apk
Squeeze（.apk） Squeeze Lab（.apk）

落とすところから通しで貼りたい場合は、 環境構築の手順8 にコマンドがあります。

ソースからビルドして入れる場合

ソース一式の中の squeeze/ からビルドできます。署名鍵はCoreと同じ keys/ を使うので、配っているAPKと同じ鍵になり、上書きで入れ直せます。 ビルドと同時にエミュレータへ入るので adb install は要りません。

export JAVA_HOME=$(/usr/libexec/java_home -v 17)
./gradlew :squeeze:installDebug :squeeze-attacker:installDebug
$env:JAVA_HOME = (Get-Item "C:\Program Files\Eclipse Adoptium\jdk-17*").FullName
.\gradlew.bat :squeeze:installDebug :squeeze-attacker:installDebug

手順24つのアプリが共存していることを確認する

adb shell pm list packages -U | grep -E "insecureappplatform|attacker"

次の4パッケージが別々に表示されれば準備完了です。

  • com.example.insecureappplatform
  • com.example.attacker
  • com.example.insecureappplatform.squeeze
  • com.example.squeeze.attacker

Extraだけを初期化する

./tools/squeeze/reset-extra.sh

SqueezeとSqueeze Labのデータだけを消します。Core教材のデータには触れません。
